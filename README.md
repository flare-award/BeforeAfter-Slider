# Сравни — Before/After Slider

Адаптивный инструмент для сравнения двух изображений с интерактивным ползунком.

## Возможности

- загрузка фото через выбор файла или drag-and-drop;
- замена и удаление каждого изображения в любой момент;
- управление разделителем мышью, касанием и клавиатурой;
- полноэкранный режим, сброс позиции и перестановка фото;
- изображения отображаются целиком без обрезки (`object-fit: contain`);
- обработка полностью в браузере — файлы никуда не отправляются.

## Локальный запуск

```bash
npm install
npm run dev
```

Vite поднимет дев-сервер и выведет адрес в консоль (обычно http://localhost:5173).

> **Важно:** не открывайте исходный `index.html` напрямую через `file://`.
> Скрипт подключён как ES-модуль (`type="module"`), поэтому браузер заблокирует
> его загрузку по CORS, и страница окажется нерабочей. Всегда используйте
> `npm run dev` или `npm run preview`.

## Проверка production-сборки

```bash
npm run build
npm run preview
```

`npm run build` собирает статику в папку `dist/`, а `npm run preview` поднимает
локальный сервер именно на этой собранной версии — так можно убедиться, что
CSS и JS подключаются корректно перед публикацией.

## Публикация на GitHub Pages

Деплой выполняется автоматически через GitHub Actions
(`.github/workflows/deploy-pages.yml`) при каждом push в ветку `main`,
а также вручную через **Actions → Deploy to GitHub Pages → Run workflow**.

Один раз нужно включить публикацию в настройках репозитория:

**Settings → Pages → Build and deployment → Source: GitHub Actions**

В `vite.config.js` задан относительный `base: './'`, поэтому сборка одинаково
работает и в подпапке GitHub Pages (`https://<user>.github.io/BeforeAfter-Slider/`),
и при размещении содержимого `dist/` в корне любого другого статического хостинга.
